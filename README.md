# Exercícios de Python

Exercícios de lógica de programação em Python, feitos durante o curso de Análise e
Desenvolvimento de Sistemas no CEUB. Organizados por assunto, do mais simples ao mais
elaborado.

## Conteúdo

| Pasta | Assunto | Exercícios |
|---|---|---|
| [`01-entrada-e-saida`](01-entrada-e-saida) | `input`, `print`, operações aritméticas | volume da esfera, consumo de água, IMC, área do trapézio, distância entre pontos |
| [`02-condicionais`](02-condicionais) | `if` / `elif` / `else`, operadores lógicos | calculadora, classificação do IMC, par ou ímpar, peso ideal, maior de três, ordem crescente, tipo de triângulo |
| [`03-repeticao`](03-repeticao) | `while`, acumuladores, contadores, `break` | soma e contagem, média de notas, menor valor |
| [`04-funcoes`](04-funcoes) | `def`, `return`, `if __name__ == '__main__'` | soma e subtração, maior valor, horas em minutos |

## Como executar

Precisa apenas do Python 3 instalado — nenhum pacote extra.

```bash
git clone https://github.com/Eduoliver04/Atividade-em-Paython.git
cd Atividade-em-Paython
python 02-condicionais/calculadora.py
```

Todos os programas são interativos: pedem os valores pelo terminal e mostram o resultado.
